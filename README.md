# 围护碳研

围护构造的材料隐含碳计算工作台，使用 Vue 3、TypeScript 和 Vite。适用于建筑方案阶段的材料选择与替代构造研究。界面采用简体中文，所有计算在浏览器内完成。

## 启动

需要 Node.js 20.19+ 或 22.12+、npm，以及支持浏览器互斥锁的新版本浏览器。安装依赖需要网络，安装完成后构建与页面检查无需在线服务。

```sh
npm ci
npm run dev
```

打开 `http://localhost:5178/`。开发服务使用独立端口 5178。安全写入需要安全上下文；本机地址受支持，部署请使用 HTTPS。

```sh
npm run build
npm run preview
```

生产预览地址为 `http://localhost:4178/`。构建输出位于 `dist/`，可部署至静态站点托管环境。本项目只有一个页面，不需要路由回退配置。不同端口、协议和主机名拥有不同浏览器存储空间。

## 使用流程

1. **构造编辑**：新建构造，输入面积和年限，选用材料并添加构造层。厚度、损耗和寿命变动后即时计算。按室外至室内排列构造层，保存后刷新可恢复。
2. **替代方案**：保存基准，复制为替代方案，更换材料或厚度并保存。在方案比较页选择基准，并勾选一个或多个替代构造。总览同时列出各替代相对基准的强度、总量、传热系数与总厚度差值及相对比例；面积、年限、部位不一致的构造不参与差值计算，并在结果中逐条说明排除原因。两方案详细比较保持可用，可将编辑中的替代构造调整为基准口径。
3. **计算书定稿**：保存后生成定稿。定稿构造不能直接修改，可下载中文文本计算书。重新开启编辑后，历史计算书仍保持冻结的输入、材料参数与结果。
4. **材料参数**：按类别或名称筛选示例物性，也可添加带参数来源的自定义材料。已建立的材料保持原值，不同参数应建立新材料。

## 输入与输出

输入包括构造面积、计算年限、材料密度、单位质量碳因子、导热系数、层厚、施工损耗率和替换寿命。输出包括初始与替换隐含碳、每平方米生命周期强度、整个构造的隐含碳、简化传热系数，以及带冻结输入的计算书文本。

示例外墙的隐含碳强度为 90.102 千克二氧化碳当量/平方米，界面按小数位规则显示为 90.1。内部计算使用未舍入数值，目标判断和方案比较也使用未舍入数值。

## 计算边界

质量按厚度（米）乘密度计算。初始隐含碳包含损耗；每次替换采用相同材料参数，次数为 `ceil(计算年限 / 寿命) - 1`。恰好处于计算期终点的替换不计入。

简化热阻为各层厚度除以导热系数之和，加上内外表面热阻 0.11 和 0.04，传热系数为其倒数。

内置物性属于教学示例。实际工程需以经核实的参数替换。不包含运行能耗、运输、施工能耗、终结阶段、生物源碳储存、热桥、含湿修正和空腔修正。目标值用于设计比较，不作为项目合规判定。

## 保存机制

设计保存在命名空间 `solo-0004-envelope-carbon:design:v1`。使用浏览器互斥锁串行保存，并核对修订标识防止跨标签页覆盖。发现另一标签页保存后会提示重新加载；未保存构造在切换前会询问是否放弃。存储失败不会提交内存状态，读取异常也不会覆盖原数据。

最多保存 200 个构造、500 种材料、1,000 份计算书，每个构造最多 20 层。没有远程同步服务。清理浏览器站点数据会丢失当前浏览器的设计，请及时下载所需计算书。计算书下载不提供恢复整个设计的导入功能。

## 验证

本次为无测试初始化基线，测试模式为 `deferred`。不包含单元测试、测试夹具或完整 E2E 测试套件；后续代码测试任务负责补充公式边界、存储故障、完整并发场景和页面回归测试。

初始化阶段保留三条有界生产冒烟检查，它们启动临时生产预览和独立浏览器上下文，经真实页面入口操作并验证可见结果，不调用内部领域函数替代页面动作。检查使用独立源，不接触开发预览里的已有设计。

先准备浏览器（仅首次需要网络）：

```sh
npx playwright install chromium
```

然后执行：

```sh
npm run build
npm run smoke -- compose
npm run smoke -- compare
npm run smoke -- document
```

每条冒烟检查最多运行 60 秒，自动关闭浏览器与临时服务。检查内容分别为构造创建及无效厚度阻止保存、刷新恢复；材料替代、多替代总览的排除说明与不同口径保护；定稿锁定、计算书下载、重新编辑及历史冻结。没有 `npm test` 命令。

## 目录

- `src/workspace`：导航、状态编排、操作反馈与资源监听。
- `src/assemblies`：构造表单、层编辑、创建与物理边界。
- `src/materials`：示例物性、自定义材料、参数目录。
- `src/carbon`：确定性公式、结果解释与目标比较。
- `src/comparison`：同口径验证、多替代总览与两方案差值。
- `src/documents`：冻结计算书、历史显示与文本下载。
- `src/persistence`：存储解码、互斥保存和初始设计。
- `src/shared`：项目样式、格式化与标识。
- `scripts/smoke.mjs`：有界页面冒烟入口，不计入生产代码规模。

项目使用组合式 API 和类型化组件契约。根组件只组合工作面，领域计算不依赖 Vue，持久化变更通过单一提交入口执行。

## 环境变量与开发约定

应用无必需环境变量，无密钥或外部接口。冒烟检查可通过 `CHROMIUM_PATH` 指定已安装的 Chromium 可执行文件；未指定时使用 Playwright 管理的浏览器。

锁文件使用 npm 支持的版本 1 格式，固定依赖解析，`.npmrc` 保持重建格式一致。使用 `npm ci` 安装；不要将宿主系统的依赖目录复制到不同系统。

```sh
npx prettier --check 'src/**/*.{ts,vue,css}' vite.config.ts
```

统一项目名：`solo-0004-envelope-carbon`。容器副本目标为 `/workspace/solo-0004-envelope-carbon`，不附带宿主机依赖和构建输出，在容器内先执行 `npm ci`。
